# ExHentai

E-Hentai / ExHentai extension for Tachimanga.

[Add extension repository](https://raw.githubusercontent.com/pujx233/cursed-manga-extensions/exhentai-test-repo/index.min.json) · Version **1.4.37**

Supports Popular, Watched tags, Favorites and language filtering in one source. Popular is available in the Gallery list selector; it uses the website's fixed list. Chapter dates use the gallery's Posted time, and login cookies stay synchronized with WebView.

The reader starts after the first gallery directory and resolves later directories only when their images are requested. Details and chapter dates share the opening request. HTML parsing, cookie access and bounded caches reduce work across browsing, search and reading.

All former language sources use the app's migration feature to move to the unified source.
